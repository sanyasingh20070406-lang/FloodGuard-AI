# FloodGuard AI dashboard prototype

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a browser. Internet is needed for the map tiles and Leaflet map library.
3. Adjust the rainfall slider and duration to see illustrative risk scores and map zones change.
4. Use “Report local flooding” to add a local-only demo report.
5. Use “Export snapshot” to download a JSON snapshot.

## Important
This is a frontend hackathon prototype. The rainfall, risk scores, and listed areas are simulated and are not live predictions or official evacuation guidance. Do not use it for real-world emergency decisions. To make it production-ready, connect trusted weather/flood data sources, validate the model, and use verified emergency contacts/routes.
